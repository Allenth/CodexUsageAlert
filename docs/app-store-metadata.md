# Mac App Store 上架资料

本文档记录已经确定的商店配置，以及提交前仍需准备的公开资料。

## 已确定

| 项目 | 决定 |
| --- | --- |
| 分发平台 | Mac App Store |
| 价格 | 免费 |
| 订阅 | 无 |
| App 内购买 | 无 |
| 官方网站 | <https://typewhale.com/> |
| 用户提供的网址 | <https://www.typewhale.com/>，当前会跳转到规范地址 `https://typewhale.com/` |
| 数据处理 | 本机处理，不要求用户提供密码、Cookie 或 API Key |
| 产品关系 | 独立第三方工具，不是 OpenAI 官方产品 |

因为应用免费且没有内购，本项目不设计购买、订阅、恢复购买、收据校验或付费墙功能。

## 提交前需要建立的网站页面

目前网站主页可以正常访问，但以下应用专属地址尚未建立：

- 建议支持页：`https://typewhale.com/codex-usage-alert/support`
- 建议隐私政策：`https://typewhale.com/codex-usage-alert/privacy`
- 可选产品介绍页：`https://typewhale.com/codex-usage-alert`

页面最低内容：

### 支持页

- 应用名称、系统要求和安装说明。
- Codex 未安装、未登录、权限失效和通知无法出现时的处理方法。
- 联系方式或问题反馈入口。
- 当前版本号和常见问题。

### 隐私政策

- 额度和 Token 数据从本机 Codex 环境读取。
- 应用不收集账号密码、Cookie、API Key 或完整运行日志。
- 本地保存的数据类型，例如设置、当日基线和已通知阈值。
- 是否使用分析、广告、崩溃收集或第三方 SDK。
- 用户如何清除本地数据和联系开发者。

## 待准备的商店字段

- [ ] 应用正式中文名和英文名。
- [ ] 副标题、简短介绍和完整描述。
- [ ] 关键词、主分类和次分类。
- [ ] 简体中文和英文截图。
- [ ] 支持网址、隐私政策网址和营销网址。
- [ ] 年龄分级、内容版权和加密出口合规答案。
- [ ] 审核备注、Codex 环境要求和可复现测试步骤。
- [ ] App Store 图标和最终版本号。

## 不得写入仓库的资料

- Apple ID 密码和双重验证码。
- App Store Connect API 私钥。
- 签名证书私钥或导出的 `.p12` 密码。
- GitHub、Codex 或其他服务的访问令牌。
- 税务、银行或身份证明资料。
