# 双服务界面实现与验收约定

这是现有 macOS 操作界面的扩展，沿用深蓝底色、系统字体、青色口袋强调色和原有操作。Grok Bot 使用紫色；选中态同时用勾选标记表达。用户任务指定的两张 `docs/design-v2/` 设计图在当前工作区缺失，因此按文字布局实现，未进行设计图逐像素比对。

## Direction contract

- THESIS：一眼比较两个服务的周期额度，切换查看独立的当日用量。
- OWN-WORLD：继承原应用的深蓝背景、紧凑卡片和系统控件；青色对应口袋，紫色对应 Grok Bot，橙色表示需处理状态。
- STORY：先看总体状态与两个用量环，再选服务查看增量、预算及 Token 或任务计数，最后处理共用预警和设置。
- FIRST VIEWPORT：380pt 宽面板，上方标题与状态，双卡、分段切换、三项指标、预算、用量卡、预警和原有按钮；底部标明两项数据来源。高度按屏幕可用区域收缩，内容可滚动。
- FORM：用户任务明确指定布局；seed: none (unavailable)。原生 SwiftUI，无网页检测器。
- FINISH：检查真实数据、未接入、过期、手动校验和设置界面；保留本机截图供复核。既有视觉系统不另行替换。

## 验收范围

自动测试覆盖 JSON、时效、每日去重、跨日、周期重置、旧版迁移和最高值聚合。原生界面检查双卡及切换、真实口袋数据、Grok 状态、手动录入和开关。系统通知横幅受 macOS 授权控制，不把规则单元测试等同于横幅实际送达。
