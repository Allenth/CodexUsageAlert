# 双服务界面实现与验收约定

这是现有 macOS 操作界面的扩展，沿用深蓝底色、系统字体、青色口袋强调色和原有操作。Grok Bot 圆环使用紫色；选中态采用青色描边、填充分段按钮及辅助功能选中属性。设计依据为 [Codex 原图](design-v2/design-codex.png) 与 [Grok Bot 原图](design-v2/design-grok.png)。0.3.0 已按两图校准布局，并用安装版主窗口及菜单栏面板检查实际渲染。

## Direction contract

- THESIS：一眼比较两个服务的周期额度，切换查看独立的当日用量。
- OWN-WORLD：继承原应用的深蓝背景、紧凑卡片和系统控件；青色对应口袋，紫色对应 Grok Bot，橙色表示需处理状态。
- STORY：先看总体状态与两个用量环，再选服务查看增量、预算及 Token 或任务计数，最后处理共用预警和设置。
- FIRST VIEWPORT：380 × 620pt 面板，上方标题、最近更新时间与需注意服务数量；横向双环卡、全宽服务切换、三项独立指标、预算、紧凑用量卡、两条独立服务状态和原有按钮；底部标明来源、版本与刷新频率。高度按屏幕可用区域收缩，内容可滚动。
- FORM：用户任务明确指定布局；seed: none (unavailable)。原生 SwiftUI，无网页检测器。
- FINISH：检查真实数据、未接入、过期、手动校验和设置界面；保留本机截图供复核。既有视觉系统不另行替换。

## 验收范围

自动测试覆盖 JSON、时效、每日去重、跨日、周期重置、旧版迁移和最高值聚合。原生界面检查双卡及切换、真实口袋数据、Grok 状态、手动录入和开关。系统通知横幅受 macOS 授权控制，不把规则单元测试等同于横幅实际送达。

## 0.3.0 设计校准交接

- 两张用户提供的原图已移动到 `docs/design-v2/`；服务名称保留口袋（Codex）和 Grok Bot，应用名称不变。
- 统一深蓝表面、青色选中态、紫色 Grok 圆环、绿色预算条；重置日期与圆环横向并排，详情摘要和操作按钮遵循原图层级。
- 原图数据为示例，实际界面保持真实数据：Grok Bot 的本地文件显示 42.8%、11 月 10 日重置，详情剩余 57.2%，今日／本周期任务均为 0；未修改数据文件。
- Token 默认显示今日及本月摘要，点击可展开原有统计与七日图表。当前接口未提供额度周期 Token 汇总，因此显示“本月”；缺少今天的记录时显示“待更新”，不使用示例数字。
- 原图中的速度预测没有可靠输入，本次提示使用真实今日增量和剩余重置天数。通知状态保留系统实值，本机为“未允许”。
- 验证：最终 `swift build && swift test` 成功（19 项 XCTest，零失败）；Release 打包与安装后签名校验通过；原生界面核对两个服务选中态、菜单栏面板、主窗口、加载态、Token 展开／收起、设置打开／关闭。
- 本机复核截图保存在被 Git 忽略的 `.impeccable/review/design-v2-codex.png`、`.impeccable/review/design-v2-grok.png`。没有将私有用量截图纳入发布；通知横幅、VoiceOver 朗读及其他 macOS 版本未验证。
