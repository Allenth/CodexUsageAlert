Codex Usage Alert / Codex 用量预警
版本 0.1.1

一、安装

1. 双击打开 DMG。
2. 将“Codex Usage Alert”拖到旁边的“Applications”文件夹。
3. 打开“应用程序”，启动“Codex Usage Alert”。
4. 首次运行时，按照 macOS 提示允许通知。

如果系统提示无法验证开发者，请在“应用程序”中右键点击 App，选择“打开”，再确认一次。完成 Apple 公证的版本通常不需要这一步。

二、使用前提

- macOS 13 或更高版本。
- 本机已经安装并登录 Codex CLI，或已经登录支持 Codex 的 ChatGPT/Codex macOS 应用。
- 应用不会要求你的账号密码、Cookie 或 OpenAI API Key。

三、如何使用

1. 启动后，菜单栏会出现 Codex 图标和当前周期已用百分比。
   如果提示 Codex 尚未就绪，请点击“打开 Codex/ChatGPT”，确认已经登录；应用会稍后自动刷新。
2. 点击菜单栏图标可查看周期额度、今日增加、每日预算、Token 使用量和重置时间。
3. 点击“立即刷新”可手动更新数据。
4. 点击“测试通知”可确认 macOS 通知是否正常。
5. 点击齿轮可以设置刷新频率、固定刷新时间和 Token 数量单位。
6. 建议开启“登录时自动启动”，以便持续监控用量。

四、预警规则

- 默认按今日增加 5%、10%、15%、20% 分级提醒。
- 同一预警等级每天只提醒一次，避免重复打扰。
- 20% 是应用的个人每日预算，不是 OpenAI 官方硬限制。
- 应用会根据额度周期估算可持续日均，并把符合条件的昨日余量结转到今天。
- 周期额度和 Token 数据由 Codex 服务端返回；本机今日增量、昨日额度与结转预算依赖此电脑的连续快照。换电脑后会从首次刷新开始记录，无法回溯另一台电脑上的本地历史。

五、常见问题

没有数据显示：
先打开 Codex 或 ChatGPT/Codex 应用确认已经登录，然后回到本应用点击“立即刷新”。

收不到通知：
打开“系统设置 → 通知 → Codex 用量预警”，允许通知；也可以在应用中点击“测试通知”。

菜单栏没有图标：
重新打开应用；如果菜单栏空间不足，请暂时退出部分菜单栏应用后再检查。

六、隐私

用量数据只在本机读取和显示。应用不上传账号凭据，不包含广告、遥测或第三方分析 SDK。
